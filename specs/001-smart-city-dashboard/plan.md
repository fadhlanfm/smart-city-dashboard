## Summary

A production-ready, full-stack Smart City Operations & Asset Management Dashboard built
with Next.js 14+ (App Router), strict TypeScript, and a four-service data backend
(PostgreSQL/PostGIS + Prisma, MongoDB/Mongoose, Redis/ioredis, Elasticsearch). The UI
is composed entirely of Shadcn UI components on Tailwind CSS. The map is powered by
MapLibre GL JS with Turf.js for client-side spatial calculations. The CI/CD pipeline
uses GitHub Actions with Jest unit tests and SonarQube code quality gates enforced on
every push and pull request.

## Implementation Notes

### Key Technical Decisions

1. **PostGIS via `$queryRaw`**: Prisma does not support PostGIS geometry natively.
   All spatial operations use `prisma.$queryRaw` with tagged template literals.

2. **Recharts over Chart.js**: Chosen for native React component API and TypeScript types.

3. **MapLibre layer stack**: Five layers - basemap, choropleth (fill), POI markers
   (circle + symbol), heatmap, spatial tool overlays. Managed by Zustand `mapStore`.

4. **Cache-aside with graceful degradation**: Redis failures log via Pino and
   fall through to primary data sources without crashing.

5. **NextAuth.js v5 JWT sessions**: GitHub OAuth2 and Credentials provider (Dummy Login) as default. Session validated in
   Next.js Middleware for all protected routes.

6. **T3 Env (`env.mjs`)**: Zod-validated environment variables; fast-fail on startup.

7. **Vercel Read-Only Mock Strategy**: Since Vercel uses a read-only filesystem and does not deploy persistent DB containers natively without explicit cloud infrastructure configuration, CRUD operations (Create/Update/Delete) for assets use a complex client-side local storage hydration mechanism to intercept mock service endpoints and ensure the UI operates perfectly in demonstration scenarios.

### Testing Strategy

- **Unit tests** (`__tests__/services/`): All service functions with mocked DB clients.
- **Unit tests** (`__tests__/api/`): Route Handler logic with mocked services.
- **Unit tests** (`__tests__/components/`): React Testing Library; ARIA role assertions.
- **E2E** (`e2e/`): Playwright for US1 (dashboard), US2 (map), US4 (search).
